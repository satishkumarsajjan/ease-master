## Directory Overview

- **`app/`**: Next.js App Router surfaces — landing, docs engine, app workspace, API routes.
- **`components/ui/`**: Reusable atomic primitives adhering to Satisium tokens.
- **`components/mdx/`**: MDX-exclusive documentation components (`Steps`, `PromptBlock`, `FileTree`).
- **`content/docs/`**: Markdown source pages rendered by Fumadocs.
- **`lib/`**: Framework-free utilities, route constants, typed navigation, and telemetry.
