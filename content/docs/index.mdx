**Ease** is an interactive cubic-bezier editor and spring physics studio designed for modern design engineers. Craft, inspect, and fine-tune fluid motion curves and mathematical spring dynamics, then export production-ready code directly into CSS, Tailwind CSS, Motion, and GSAP.

## Core Capabilities

- **Interactive Cubic-Bezier Editor:** Drag control handles with sub-pixel precision and real-time bounding box adjustments.
- **Analytical Spring Physics Solver:** Tune physical mass, stiffness, damping, and initial velocity with instant numerical integration.
- **Multi-Property Live Preview:** Test your curves simultaneously across translation, scale, opacity, and rotation in an interactive stage.
- **Universal Code Export:** One-click copy formatted for native CSS `cubic-bezier()`, modern CSS `linear()` spring approximations, Tailwind CSS v4 keyframe configs, Motion spring transitions, and GSAP `CustomEase`.

## The Studio Architecture

The Ease studio is located at [`/app`](/app). It features a 3-column workstation:

1. **Left Rail:** Catalog of standardized cubic-bezier presets and calibrated physical springs.
2. **Center Canvas:** Real-time graph visualizer with dynamic auto-zoom and multi-property animation preview stage.
3. **Right Rail:** Curve behavioral characteristics, recommended use-cases, and multi-target code generation.
